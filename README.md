**DownSort** is a high-performance, 100% local, privacy-first desktop application designed to automatically scan, classify, and organize cluttered download folders into clean, intuitive directories.

Unlike standard extension-based sorters, DownSort performs **deep content inspection** (e.g., local PDF text parsing, image resolution & aspect ratio analysis, media release tag classification).

---

## ✨ Key Features

### 1. 🔍 Deep PDF Sub-Classification
Instead of dumping all PDFs into a single generic directory, DownSort inspects filenames and extracts text locally to accurately categorize:
- 🎫 **Admit Cards & Hall Tickets**: Exam hall tickets (GATE, TCS NQT, AFCAT, NTA, ISRO, roll numbers, venues, reporting times).
- 🎓 **PYQ Papers & Question Papers**: Previous year question papers, sample papers, model papers, semester examinations.
- 📖 **Notes & Study Material**: Lecture notes, university modules, handwritten notes, assignments, and lab manuals.
- 📜 **Certificates & Credentials**: Completion certificates (Coursera, Udemy, IBM, NPTEL, HackerRank, internships).
- 🛡️ **Government IDs & Official Docs**: Aadhaar, PAN card, voter ID, marksheets, affidavits, declarations.
- 🧾 **Applications, Invoices & Receipts**: Application forms, fee receipts, tax invoices, payslips.
- 📄 **Research Papers & Preprints**: ArXiv papers, conference papers, IEEE proceedings.
- 👤 **Resumes & CVs**: Resumes and curriculum vitae.
- 📁 **Other PDFs**: Any single or unique PDF that does not match standard categories is routed into `PDFs/Other`.

### 2. 🖼️ Smart Image Categorization
- 💬 **WhatsApp Images**: Filenames matching WhatsApp media format (`IMG-YYYYMMDD-WA*`).
- 👤 **Photos & Signatures**: Scanned signatures (detected via aspect ratio or naming patterns), passport photos, and profile pictures.
- 🌄 **Wallpapers & Backgrounds**: High-resolution images (1080p, 2K, 4K, 16:9 widescreen or 9:16 mobile wallpaper aspect ratios).
- 📸 **Screenshots**: Screen captures and snips.
- 🤖 **AI Generated Images**: Images generated by ChatGPT (DALL-E), Gemini, Midjourney, Stable Diffusion.
- 🪪 **Scanned Documents & Cards**: Scanned marksheets, certificate images, college ID cards.
- 🖼️ **General Images**: Any other graphics and pictures.

### 3. 🎬 Video & Movie Categorization
- 🍿 **Movies & Series**: High-definition releases (1080p, 2160p 4K, HEVC, WEB-DL, BollyFlix, YTS) and video files > 500 MB.
- 📹 **Screen Recordings**: OBS recordings, Zoom meetings, and screen recordings.
- 🎥 **General Videos**: Short clips, tutorials, and standard video files.

### 4. 📱 APKs, Software & Documents
- 📱 **Android APKs**: `.apk`, `.xapk`, `.apks`, `.aab` packages.
- 📦 **Installers**: `.exe`, `.msi` software installers.
- 🗜️ **Archives**: `.zip`, `.rar`, `.7z`, `.tar`, `.gz`.
- 📑 **Office & Code**: Word (`.docx`), Excel (`.xlsx`), PowerPoint (`.pptx`), Code (`.py`, `.ipynb`, `.js`, etc.).

---

## 🔒 Safety & Privacy Guarantees
- **100% Local & Offline**: All processing happens entirely on your machine. Zero cloud dependencies, zero data tracking.
- **Conflict Prevention**: If a file with the same name already exists in the destination folder, DownSort safely renames it to `file (1).ext` without overwriting data.
- **1-Click Rollback / Undo**: Every organization batch is logged. With one click in the **History & Undo** drawer, every file is restored back to its original location.
- **Move vs Copy Mode**: Choose between moving files directly or copying them first to test.

## 🚀 Quick Start

### Prerequisites
- Python 3.10 or higher
- Git

### Installation
```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/DownSort.git
cd DownSort

# 2. Install dependencies
pip install -r requirements.txt
```

### Launch Web Dashboard
```bash
python run.py
```
This automatically starts the local server and opens `http://127.0.0.1:5050` in your default browser.

### Windows One-Click Launcher
Double-click `Launch_DownSort.bat` in the project folder.

---

## 💻 Command-Line Interface (CLI)

Prefer the terminal? DownSort has full CLI support:

```bash
# Preview how files will be categorized (dry-run)
python cli.py --scan

# Organize files using Move mode
python cli.py --organize --mode move

# Organize files using Copy mode (safe testing)
python cli.py --organize --mode copy

# View organization history
python cli.py --history

# Rollback / Undo the latest organization run
python cli.py --undo latest
```
