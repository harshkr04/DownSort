The Intelligent Download Folder Sorter You've Always Needed

Stop losing important files in a cluttered Downloads folder. DownSort uses local PDF text analysis and image metadata inspection to organize files into clean, categorized directories with 1-click rollback.

View on GitHub Explore Features
# 1-Minute Quick Start
git clone https://github.com/harshkr04/DownSort.git
cd DownSort
pip install -r requirements.txt
python run.py
🔍
Deep PDF Sub-Classification
Reads PDF text locally to automatically sort Admit Cards, PYQ question papers, lecture notes, certificates, and ID docs. Single/unique PDFs are filed to PDFs/Other.
🖼️
Smart Image & Wallpaper Sorter
Detects WhatsApp media, passport photos & signatures (via aspect ratio), high-resolution desktop wallpapers (1080p, 4K), and screenshots.
🎬
Movies, APKs & Software
Categorizes high-definition movie releases, screen recordings, Android APKs, and desktop installers (.exe, .msi) automatically.
↩️
1-Click Undo / Rollback
Full transaction ledger. If you don't like the organization results, one click restores every single file back to its exact original location.
🛡️
100% Offline & Private
Zero external network calls. All file scanning, PDF reading, and image analysis execute locally on your machine.
💻
Web Dashboard & CLI
Use the modern interactive web interface or run lightning-fast batch scans directly from PowerShell/terminal with cli.py.
